# Third-party dependencies

This project expects libtesla as an external dependency under `lib/libtesla`.

- libtesla: https://github.com/WerWolv/libtesla
- nx-ovlloader: https://github.com/ppkantorski/nx-ovlloader
- devkitPro libnx/devkitA64: https://devkitpro.org/

The project source in this repository does not bundle third-party source code.
Refer to each dependency's upstream license for redistribution requirements.
